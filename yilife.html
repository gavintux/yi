把網頁放在 `gavintux.github.io/yi/yilife.html`，API Key 如何處理最妥當？

因為 GitHub Pages 的原始碼對全世界公開，若將 `AIzaSy...` 直接寫在 `yilife.html` 裡，推上 GitHub 幾秒內就會被自動化爬蟲掃描並遭到停權或盜刷。以下是 3 種最妥當的處理方式：

1. `yilife.html` 程式碼裡完全不放 Key。

3. 到 Google Cloud Console 點開該 API Key，在「網站限制 (HTTP Referrers)」加入： 

https://gavintux.github.io/*
http://gavintux.github.io/*
